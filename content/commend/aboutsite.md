先说实话：这个博客不是我写的代码，是我用 AI 帮着搭的。

但整个折腾过程——从选方案到部署到日常维护——全是我自己一路摸过来的。写这篇就是记录一下我都用了什么、怎么弄的，给也想自己搞个博客的人参考。

## 为什么搞成现在这样

一开始想得很简单：有个地方能放我写的东西，看起来别太丑，最好还能有点"高级感"。

试过几个现成的博客平台，总觉得太死板。后来发现 **Quartz** 这个东西——它能把 Markdown 笔记变成网站，还自带双向链接和图谱，看起来挺酷的。而且它和 Obsidian 配合得特别好，我本来就在用 Obsidian 记笔记，相当于写完了直接就能发布，省了很多事。

## 用到的技术栈（其实就是几个工具）

说起来好像很专业，其实就这几样：

- **[Quartz](https://quartz.jzhao.xyz/)**：核心引擎，负责把 Markdown 文件变成网站。开源免费，配置起来不算太难，照着文档一步步来就行。
- **GitHub**：用来存所有笔记和配置文件，也充当版本管理。改坏了还能回滚，对新手很友好。
- **Cloudflare Pages**：托管和自动部署。每次我在 GitHub 上推送更新，它会在几十秒内自动重新构建整个网站并发布，不需要我手动操作。域名也是在 Cloudflare 上买的。

说白了，我只负责写 Markdown 笔记，其他事情都是这几个工具自动完成的。

## 怎么用这个网站

- **看图谱**：右下角那个小球点开能看到所有笔记的连接关系，点哪个节点就跳到哪篇文章。
- **搜东西**：按 `Ctrl+K`（Mac 是 `Cmd+K`）可以全局搜索，想找什么直接打字就行。
- **点链接**：文章里带颜色的字都是链接，点进去就是相关内容。页面底部会显示"有哪些其他文章提到了这篇"，这个功能挺有用。

## 特别说明

这个网站所有内容都是我写的，但代码和部署过程大量借助了 AI（ChatGPT 和 Claude）。我不觉得这有什么问题——工具就是拿来用的，重要的是我想表达什么，而不是我能不能手写每一行代码。

如果你也想搭一个类似的博客，Quartz 的官方文档写得很清楚，配合 AI 帮忙调试，基本都能弄出来。有问题也可以问我，虽然我不一定会。
