# 我的第一篇知识图谱文章 — 关于这个博客的搭建与数字花园理念

欢迎来到我的数字花园（Digital Garden）！这是我搭建个人知识体系与认知地图的起点。

与传统的“流水线式”博客（按照时间顺序罗列长文章）不同，这个站点采用的是**双向链接（Bi-directional Links）**与**知识图谱（Knowledge Graph）**的形式构建。它不仅是一个文章的发表平台，更是我思维的延伸。

---

## 什么是“数字花园”？

**数字花园（Digital Garden）** 是一种与传统的“博客（Blog）”截然不同的知识分享与记录理念：

1. **常青与演进（Evergreen Content）**：这里的文章不是写完就封存的“历史档案”，而是像植物一样，随着我的思考加进、认知升级而被不断修改、补充和修剪。
2. **网状链接（Networked Thought）**：思想不是单向线性的。通过笔记之间的互相引用（双向链接），不同领域的知识在此产生交集，形成一张网。
3. **拥抱未完成（Growth over Perfection）**：在数字花园里，你不必等一篇文章“完美”后再发布。任何萌芽期的想法（Seedling）都可以先种下，再慢慢培育。

---

## 本站的技术选型与搭建

为了打造一个极致轻量、优雅且支持双向链接图谱的个人站点，我最终选择了 **Quartz + Cloudflare Pages** 的技术方案：

* **构建引擎**：[Quartz](https://quartz.jzhao.xyz/) —— 一个能将 Markdown 笔记转换为现代化网状静态站点的开源工具，原生支持 Obsidian 风格的双向链接 `[[链接]]` 和交互式关系图谱。
* **写作环境**：本地 Markdown 编辑器 / 自制可视化 Python 编辑器。
* **版本控制**：GitHub 仓库。
* **托管部署**：[Cloudflare Pages](https://pages.cloudflare.com/) —— 每次推送到 GitHub 主分支，Cloudflare 会在数十秒内自动构建并全球 CDN 加速发布。

---

## 如何探索这个站点？

1. **利用交互式图谱（Graph View）**：在页面角落或侧边栏，你可以看到全站知识节点的连接关系图。点击节点即可快速跃迁至相关概念。
2. **跟随双向链接（Backlinks）**：文章中的高亮链接会带你走向关联主题；在页面底部，你还可以看到“哪些其他文章引用了本文”。
3. **检索与标签**：通过快捷键 `Ctrl + K`（或 `Cmd + K`）搜索全局关键词或标签。
